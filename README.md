# Battleship
The game "Battleship"

Python 3.10.0
PyQt5

запуск - main.py

Правила игры.

В начале новой игры случайным образом на полях игрока и компьютера создаются корабли:

один четырёхпалубный;

два трёхпалубных;

три двухпалубных;

четыре однопалубных.
Одна палуба — одна клетка.

Ходы выполняются игроками поочерёдно.
Если одна из сторон попала в корабль противника, даётся дополнительный ход и дополнительное время с учётом серии попаданий.

В начале игры предоставляется время в 200 секунд.
Если выстрел закончился промахом, у игрока отнимается штрафное время.
Количество итоговых очков складывается из результатов ходов игрока и оставшегося времени в секундах.

Количество полученных очков = время + дополнительное время − штрафное время.

Учитывается серия попаданий:

два попадания = дополнительное время × 2;

три попадания = дополнительное время × 3 и т. д.

Уровень сложности — простой:

дополнительное время — 10 с;

штрафное время — 4 с.

Уровень сложности — средний:

дополнительное время — 5 с;

штрафное время — 3 с.

Уровень сложности — сложный:

дополнительное время — 3 с;

штрафное время — 5 с.

Игра заканчивается, если время игры закончилось или все корабли одной из сторон были поражены.
